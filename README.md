Аббасов Нахид М3307 Магазин продажи фруктов и овощей на заказ

![ER-схема базы данных](\web_qfu3.png)
##  Модели данных

###  Product (Товар)
- `id`: идентификатор
- `name`: название товара
- `price`: цена
- `categoryId`: ссылка на категорию

Связи:
- принадлежит одной `Category`
- участвует в одном или нескольких `OrderItem`

---

###  Category (Категория)
- `id`: идентификатор
- `name`: название категории

Связи:
- содержит список товаров (`Product[]`)

---

###  User (Пользователь)
- `id`: идентификатор
- `email`: email (уникальный)
- `name`: имя пользователя

Связи:
- имеет список заказов (`Order[]`)

---

###  Order (Заказ)
- `id`: идентификатор
- `userId`: идентификатор пользователя

Связи:
- принадлежит одному `User`
- содержит список позиций (`OrderItem[]`)

---

###  OrderItem (Позиция заказа)
- `id`: идентификатор
- `quantity`: количество единиц товара
- `productId`: идентификатор товара
- `orderId`: идентификатор заказа

Связи:
- принадлежит одному `Order`
- указывает на один `Product`
